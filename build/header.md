# Slideshow Mobil PDF

**EN:** Modified version of the **Slideshow** script by Zsolt Viczian from
zsviczian/obsidian-excalidraw-plugin (ea-scripts/Slideshow.md):
https://github.com/zsviczian/obsidian-excalidraw-plugin/blob/master/ea-scripts/Slideshow.md

Changes (November 2026):
- On mobile, "Create PDF" uses the native print function of Obsidian instead of `ea.createPDF`.
  This function is not part of the plugin API and may stop working after an update.
  The mobile print always requests A4 paper.
- Print dialog: swiping inside the content scrolls instead of dragging the window.
  Buttons and error messages stay visible at the bottom.
- Side panel: icon-only buttons have no padding and a fixed icon size.
- Own side panel title and runtime name.

Created with AI assistance, based on the original code by Zsolt Viczian.
Tested only on a Samsung Galaxy Tab S9 Ultra. Not affiliated with or endorsed by the original author.
